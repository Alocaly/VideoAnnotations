# Implementation roadmap

Scope: one video per project, a Rust application, and an entirely English interface.

1. **Architecture and technical prototype — completed** — Validated a native egui/eframe window and FFmpeg decoding on Windows. Open a video, display frames, and seek. UI, media, project, annotation data, and the future export boundary are separated. See [architecture](docs/architecture.md) and [validation](docs/step-1-validation.md).
2. **Video player — completed** — Persistent libmpv playback with synchronized audio, pause/replay, position/duration, fullscreen, and buttons/shortcuts for +/-1 second, +/-5 seconds, and +/-1 frame. Includes volume/mute. See [design and validation](docs/step-2-playback.md).
3. **Static annotations — completed** — Create, select, move, resize, style, and delete text, rectangles, ellipses, and arrows. Geometry uses video coordinates so resizing the preview preserves placement. Includes discard confirmation while persistence is unavailable. See [design and validation](docs/step-3-annotations.md).
4. **Annotation timeline — completed** — Edit start/end times, seek through tracks or the ruler, create annotations at the playhead, and manage overlapping annotations and stacking order. Preview and picking respect active intervals. See [design and validation](docs/step-4-timeline.md).
5. **Project persistence — completed** — Versioned .vannot files store the source-video reference and all annotation settings. Includes missing-source relinking, validated staged opening, safe replacement on save, unsaved-change protection, and annotation undo/redo. See [design and validation](docs/step-5-persistence.md).
6. **First annotated export — completed** — Export MP4 (H.264/AAC) with source audio, progress reporting, cancellation, and safe destination replacement. Shares annotation geometry and font rendering with the preview. This completes the first usable end-to-end milestone. See [design and validation](docs/step-6-export.md).
7. **Effects and additional formats — completed** — Fades, linear movement, color-pulsing glow, and a traveling outline segment for rectangles/ellipses. Shared time-based preview/export rendering, animated MP4, and looping GIF with maximum-width and frame-rate controls. See [design and validation](docs/step-7-effects-gif.md). Further formats can be selected separately.
8. **Reliability and distribution — completed for the portable preview** — Generated-media matrix (portrait, 4K, 120 fps, fractional rates, odd dimensions, pixel aspect ratios, rotation, one-hour timeline); corrected software preview rotation; release-mode export timing; Windows x64 ZIP builder, runtime diagnostics, isolated package checks, dependency setup and shortcut guide. See [validation and remaining release work](docs/step-8-reliability.md). Signed installers, bundled-runtime release review, and clean-machine/long-running testing remain separate.

Multi-clip editing, transitions between clips, and multiple video tracks are outside the initial scope.
